# PDF Dataset (Not Included in Repository)

This project uses 50 research paper PDFs for RAG (Retrieval-Augmented Generation).

The PDFs, cleaned JSON files, chunks, and FAISS index are NOT uploaded to GitHub
to avoid size issues and potential copyright concerns.

Download the original dataset from here:
https://www.kaggle.com/datasets/yasirabdaali/arxivorg-ai-research-papers-dataset

After downloading, place the PDFs inside:

    data/pdfs/

Then run:
    python structure.py
    python app.py
